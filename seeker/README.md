## Release Signing

Saved from CLI configuration:

- Keystore path: `release.keystore` (next to this file, not committed)
- Key alias: `mirmobe-sky`
- Store password env: `SOLANA_MOBILE_KEYSTORE_PASSWORD`
- Key password env: `SOLANA_MOBILE_KEY_PASSWORD`

The signing key is not in git. Create `release.keystore` once, with alias `mirmobe-sky`, and keep the file and its passwords. Every dApp Store update has to be signed with that same key. Export the password environment variables before running the CLI release build.

```bash
keytool -genkeypair -v -keystore release.keystore -alias mirmobe-sky \
  -keyalg RSA -keysize 2048 -validity 10000
export SOLANA_MOBILE_KEYSTORE_PASSWORD='…'
export SOLANA_MOBILE_KEY_PASSWORD='…'
npx solana-mobile webshell build .
```

Publishing to the Solana dApp Store is done in the publisher portal (https://publish.solanamobile.com) after identity verification. The portal needs this signed release APK, the listing copy in `store-listing.txt`, and the images in `listing/`. The package name `com.mirmobe.sky` cannot be changed after the app is created.
